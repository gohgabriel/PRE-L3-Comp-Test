# Data

All data in this folder is **synthetic and provided for competency-test purposes only**. It contains no real client information.

## `case_notes.csv`

| Column | Description |
|---|---|
| `note_id` | Note identifier |
| `client_id` | Synthetic client identifier |
| `note_date` | Synthetic date the note was recorded |
| `text` | The note text, written in the client's own words (a self-report, not a caseworker note) |
