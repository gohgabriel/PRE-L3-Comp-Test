# Data Analyst Competency Test

Everything you need is in **[`competency_test.ipynb`](competency_test.ipynb)**: instructions, questions, and space for your answers.

- **Run it in your browser:** open the notebook and click *Open in Colab*.
- **Run it locally:** *Code → Download ZIP*, install `requirements.txt`, and open the notebook in Jupyter or VS Code.

The data in `data/` is synthetic and provided for this test only. See [`data/README.md`](data/README.md) for its source and licence.
